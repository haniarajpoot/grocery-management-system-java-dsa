# 🛒 Grocery Management System — Java

A console-based Grocery Management System developed in **Java** as a Data Structures and Algorithms project.

## 📌 Overview

This project demonstrates the practical application of programming and Data Structures and Algorithms concepts to develop a grocery store management application.

## ✨ Features

- Product Management
- Grocery Store Operations
- Product Searching
- Data Management
- Menu-Driven Interface
- Efficient data handling using DSA concepts

## 🛠 Technologies Used

- Java
- Data Structures and Algorithms
- Eclipse IDE

## 📚 Concepts Applied

- Arrays
- Searching
- Sorting
- Classes and Objects
- Functions/Methods
- Loops and Conditional Statements
- Data Organization and Management

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project in Eclipse or another Java IDE.
3. Run `finalproject.java`.
4. Follow the menu displayed in the console.
